## Para instalar qualquer um: o pedido do almoxarifado

```
Leia o README de [link do repositório]. Me diga, em poucas linhas e sem termo técnico: o que ele faz, o que precisa instalar no meu computador e se alguma parte é paga. Só instale com a minha aprovação.
```

## Quando a fonte é PDF: o docling

```
Instale o docling (github.com/docling-project/docling) e converta os PDFs desta pasta para markdown, mantendo as tabelas. Me mostre uma tabela convertida ao lado da original, para eu conferir.
```

O docling pede **Python 3.10 ou mais novo** (README do docling: o suporte ao 3.9 saiu na versão 2.70.0).
